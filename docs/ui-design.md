# MAUI App 产品体验与 UI 设计规范

本文档定义 PrivateCloudDrive MAUI App 的产品体验、核心页面、设计系统和组件规范。目标是让后续 ABP 后端接口、MAUI 页面、视图模型和自动化测试可以按同一标准落地。

## 1. 设计目标

- 移动端优先，首批适配 Android 与 iOS。
- 产品形态是长期使用的文件与媒体管理工具，不做营销页、不做欢迎广告、不使用花哨渐变和装饰背景。
- 视觉参考方向是 iCloud Drive 的清晰文件层级、Google Photos 的媒体浏览效率、Cloudreve 的私有网盘任务流。
- 内容优先：文件名、缩略图、大小、时间、上传进度、回收站状态必须比装饰元素更突出。
- 界面稳定：列表、网格、底部导航、操作菜单的尺寸固定，避免加载、选择、刷新时跳动。
- 大量文件场景优先：支持快速扫描、批量选择、分页加载、错误恢复和可理解的空状态。
- 安静界面优先：主页面按“当前状态 -> 可执行动作 -> 内容列表”的顺序组织，不做仪表盘式堆叠。
- 私有部署透明：登录页、文件页和设置页需要明确显示当前服务地址或服务状态，方便内测排障。

## 2. 信息架构

### 2.1 底部导航

当前 MAUI 主导航固定 5 个入口。Android 上必须保持 5 个以内，避免 Shell 自动生成英文 `More` 溢出入口。

| Tab | 标题 | 目标 | 默认页 |
| --- | --- | --- | --- |
| Files | 文件 | 浏览文件夹、文件、搜索筛选和常用整理操作 | 文件首页 |
| MediaLibrary | 媒体库 | 按时间线浏览图片、视频和处理状态 | 媒体库页 |
| Albums | 相册 | 把图片和视频整理成可回看的集合 | 相册页 |
| Uploads | 上传 | 查看上传队列、失败原因和完成记录 | 上传队列页 |
| Settings | 设置 | 账号、空间、登录方式、服务与安全入口 | 设置页 |

交互规则：

- 未登录时只显示启动页或登录页，不显示底部导航。
- 登录后默认进入 Files。
- Uploads 有进行中或失败任务时显示角标，角标只显示数量或失败点，不显示长文本。
- 详情、预览、播放页作为导航栈页面打开，不占用底部导航入口。
- 回收站、我的分享、操作日志从 Settings 的“常用管理”选项列表进入，不占用底部导航。
- 分享设置、媒体处理、相册详情作为导航栈页面打开。

### 2.2 顶部栏

主 Tab 页面使用无导航栏的沉浸式页头：大标题、简短说明和右侧主要动作。导航栈详情页仍使用 52 到 56 高度顶部栏，左侧为返回按钮，右侧为当前页面操作。

品牌 Logo 的使用规则：

- 登录页顶部必须显示 PrivateCloudDrive 品牌标识。
- 设置页右上角可以显示 44 x 44 品牌图标，作为账号与私有云状态提示的一部分。
- 文件、媒体库、相册、上传主工作流不放装饰性 Logo，优先展示当前位置、媒体数量、队列状态等上下文。

页面标题规则：

- 文件首页显示“文件”，当前路径放入位置概览卡。
- 媒体库页显示“媒体库”。
- 相册页显示“相册”。
- 上传页显示“上传”。
- 回收站页显示“回收站”。
- 设置页显示“设置”。

### 2.3 操作层级

- 高频操作使用页头按钮或页面内主按钮：刷新、上传、新建文件夹、新建相册、清除已完成。
- 中频操作放入列表项或选项列表：详情、删除、恢复、下载、进入回收站、进入分享管理、进入操作日志。
- 批量操作通过显式“选择”模式进入，操作条固定展示已选数量和可执行动作。
- 登录方式、服务地址、安全状态放入 Settings 的列表组，避免散落成多个孤立卡片。
- 高风险操作必须二次确认：删除、永久删除、清空回收站、取消分享、解绑外部账号、退出登录。

## 3. 设计系统

### 3.1 颜色

整体以中性灰、白色、少量绿色主色和状态色组成。避免大面积单一绿色、紫色、蓝紫渐变、米色或深蓝背景。

| Token | 浅色模式 | 深色模式 | 用途 |
| --- | --- | --- | --- |
| `Color.Background` | `#F7F9FC` | `#0F1720` | 页面背景 |
| `Color.Surface` | `#FFFFFF` | `#161F2A` | 列表、底部导航、菜单 |
| `Color.SurfaceAlt` | `#F1F5F9` | `#1F2937` | 搜索框、筛选条、上传行背景 |
| `Color.TextPrimary` | `#17202A` | `#F8FAFC` | 主文本 |
| `Color.TextSecondary` | `#607083` | `#B6C2CF` | 元数据、说明 |
| `Color.TextTertiary` | `#8A98A8` | `#7C8896` | 占位、禁用 |
| `Color.Border` | `#E2E8F0` | `#2D3748` | 分割线、边框 |
| `Color.Primary` | `#1F7A5C` | `#7EC9B0` | 主按钮、选中状态 |
| `Color.PrimarySoft` | `#D8EFE7` | `#183E34` | 选中背景、轻提示 |
| `Color.Info` | `#275B89` | `#7BA7D8` | 链接、信息 |
| `Color.Warning` | `#B76E00` | `#F5B45B` | 暂停、容量接近上限 |
| `Color.Danger` | `#B42318` | `#FF8A80` | 错误、删除 |
| `Color.Success` | `#15803D` | `#86D99A` | 上传完成、保存成功 |

落地要求：

- 主色只用于可交互重点，不用于大面积背景。
- 删除、解绑、清空队列等危险操作统一使用 `Danger`。
- 缩略图加载失败时使用 `SurfaceAlt` 背景加文件类型图标，不使用醒目色块。
- 深色模式不使用纯黑作为普通页面背景，视频和图片预览页例外。

### 3.2 字体

默认使用 MAUI 项目已有 OpenSans，平台字体不可用时回退系统字体。

| 层级 | 字号 | 字重 | 行高 | 用途 |
| --- | --- | --- | --- | --- |
| PageTitle | 28 | Semibold | 34 | 主 Tab 页面标题 |
| StackTitle | 22 | Semibold | 28 | 详情、预览、设置子页面标题 |
| SectionTitle | 17 | Semibold | 24 | 分组标题 |
| Body | 15 | Regular | 22 | 文件名、正文 |
| BodyStrong | 15 | Semibold | 22 | 重要文件名、用户名 |
| Meta | 13 | Regular | 18 | 大小、时间、路径 |
| Caption | 12 | Regular | 16 | 状态、角标、辅助信息 |
| Button | 15 | Semibold | 20 | 按钮文本 |

文本规则：

- 不使用随屏幕宽度变化的字体。
- 文件名最多两行，第二行截断；列表模式默认一行截断。
- 按钮文本必须完整显示，短按钮优先使用图标。
- 中文、英文、数字混排时不使用负字距。

### 3.3 间距与布局

- 基础间距单位为 4。
- 页面左右边距：手机 16，平板 24。
- 列表项内边距：水平 16，垂直 10 到 12。
- 图标与文本间距：8。
- 分组标题上边距：20，下边距：8。
- 底部导航高度：60 到 64，需避开安全区。
- 触控目标最小 44 x 44。

### 3.4 圆角与边框

- 主按钮、输入框、搜索框、文件卡片：8。
- 缩略图：6。
- 小标签、状态胶囊：6。
- 列表项默认无卡片边框，以分割线和留白区分。
- 不做卡片套卡片。

### 3.5 图标

图标风格使用线性、单色、24px 主尺寸。实现建议使用 `FontImageSource` 绑定统一图标字体，避免每个页面手写 SVG。

核心图标语义：

- 文件夹：folder
- 图片：image
- 视频：video
- 上传：upload
- 下载：download
- 更多：more-horizontal
- 搜索：search
- 排序：arrow-up-down
- 视图切换：list / grid
- 删除：trash
- 回收站：archive-restore
- 恢复：rotate-ccw
- 设置：settings
- 播放：play
- 暂停：pause
- 重试：refresh-cw
- 分享：share，V1
- 收藏：star，V1
- 标签：tag，V1

状态规则：

- 未选中图标使用 `TextSecondary`。
- 选中图标使用 `Primary`。
- 禁用图标使用 `TextTertiary`。
- 危险操作图标使用 `Danger`。

## 4. 组件规范

### 4.1 按钮

| 类型 | 样式 | 用途 |
| --- | --- | --- |
| Primary | 主色背景、白色文本、8 圆角 | 登录、保存、确认上传 |
| Secondary | `SurfaceAlt` 背景、主文本 | 取消、选择目标目录 |
| Text | 透明背景、主色文本 | 次要链接 |
| Icon | 44 x 44，透明或浅背景 | 搜索、排序、更多 |
| Danger | 透明或浅红背景、红色文本 | 删除、解绑、退出 |

规则：

- 一个页面同一层级最多一个 Primary。
- 表单底部按钮固定顺序：取消在左，确认在右。
- 加载中按钮禁用并显示小型 ActivityIndicator。

### 4.2 输入框

- 高度 44 到 48。
- 背景 `SurfaceAlt`，边框 `Border`。
- 聚焦边框 `Primary`。
- 错误文本显示在输入框下方，字号 12，颜色 `Danger`。
- 密码框必须有显示/隐藏图标。

### 4.3 状态概览卡

状态概览卡用于文件、媒体库、相册、上传和设置页的首屏信息。它不是装饰卡片，必须回答用户当前最关心的问题。

内容结构：

- 左侧：42 到 58 的线性图标或品牌标识，使用 `PrimarySoft` 背景。
- 中间：状态标题或主数字，例如“当前位置”“4 项媒体”“上传队列”“50.33 MB 已使用”。
- 下方：上下文说明，例如服务地址、图片/视频数量、队列摘要、配额剩余。
- 右侧：最多一个主要动作，例如“返回”“处理”“新建”“清除已完成”“回收站”。

规则：

- 一个主 Tab 首屏最多一个状态概览卡。
- 不把状态概览卡嵌套进其他卡片。
- 概览卡圆角不超过 10 到 12，边框使用 `Border`，不使用重阴影。
- 状态文案必须可独立理解，不只依赖图标。

### 4.4 选项列表组

选项列表组用于 Settings 的“常用管理”“登录方式”“服务与安全”，也可用于后续详情页的管理入口。

内容结构：

- 分组标题使用 `SectionTitle`。
- 外层使用一个 `Surface` 容器，内部按行排列。
- 每行左侧为 42 到 44 图标或服务缩写，中间为标题和说明，右侧为箭头、状态或按钮。
- 行高 70 到 84；登录方式等带状态按钮的行可增加到 82。
- 行间使用内缩分割线，不使用横向入口卡片。

规则：

- 常用管理入口必须使用列表形式，不使用横向卡片。
- 每行只能承载一个主意图；复杂状态通过说明文本或右侧状态表达。
- 危险入口不混在普通列表中，退出登录独立置底。

### 4.5 文件列表项

文件列表项用于文件页、回收站和上传任务。信息密度优先于装饰，行高可按操作复杂度在 72 到 116 之间变化。

内容结构：

- 左侧：44 x 44 图标或缩略图。
- 中间：文件名一行，元数据一行。
- 右侧：大小、详情、删除、状态胶囊或更多按钮；收藏图标属于 V1。

元数据格式：

- 文件夹：`12 项 · 2026-05-07`
- 文件：`24.8 MB · 2026-05-07`
- 图片：`4032 x 3024 · 3.2 MB`
- 视频：`12:34 · 1920 x 1080 · 128 MB`

滑动操作：

- MVP Core 左滑显示删除。
- V1 左滑增加分享、重命名、移动。
- 删除必须二次确认。
- 批量选择时禁用滑动操作，底部显示批量操作栏。

### 4.6 文件卡片

网格文件卡片用于文件首页的网格模式。

- 手机两列或三列，按屏宽决定。
- 卡片不使用阴影。
- 缩略图区域固定 1:1。
- 文件名显示在缩略图下方，最多两行。
- 文件夹卡片使用浅底和文件夹图标，不使用大面积高饱和颜色。

### 4.7 缩略图比例

| 类型 | 比例 | 说明 |
| --- | --- | --- |
| 图片网格 | 1:1 | 裁切填充，预览页显示完整图 |
| 视频封面 | 16:9 | 右下角显示时长 |
| 文件图标 | 1:1 | 图标居中 |
| 分享预览 | 16:9 或 1:1 | V1，根据首个媒体类型决定 |

加载策略：

- 先显示骨架块，再显示缩略图。
- 缩略图失败时显示类型图标和“无法加载缩略图”短提示。
- 不直接在列表中加载图片原图。

### 4.8 底部导航

- 高度 60 到 64。
- 图标 22 到 24，文本 11 到 12。
- 当前 Tab 使用主色，未选中使用 `TextSecondary`。
- 上传角标使用 `Danger` 表示失败，使用 `Primary` 表示进行中数量。

### 4.9 操作菜单

移动端使用底部菜单。菜单项高度 48。

排序：

1. 主要动作：打开、播放、预览。
2. 管理动作：详情、下载、恢复。
3. V1 管理动作：重命名、移动、标签、收藏。
4. V1 分享动作：分享、复制链接。
5. 危险动作：删除、永久删除、取消分享、解绑。

危险动作放在最后，并用 `Danger`。

### 4.10 上传进度组件

上传队列项高度 76 到 88。

内容：

- 文件名。
- 目标目录。
- 进度条，高度 4。
- 进度文案：`45% · 2.1 MB/s · 剩余 01:23`。
- 状态按钮：暂停、继续、取消、重试。

状态：

- Waiting：灰色进度条，显示“等待上传”。
- Uploading：主色进度条。
- Paused：警告色，显示“已暂停”。
- Failed：红色，显示错误摘要和重试按钮。
- Completed：成功色，2 秒后可折叠到完成记录。

### 4.11 媒体预览组件

图片和视频预览页允许使用黑色背景，因为内容本身需要沉浸展示。

通用规则：

- 顶部工具栏默认半透明，轻触隐藏或显示。
- 底部操作栏包含详情、下载；收藏和分享属于 V1。
- 错误状态必须保留返回按钮。

图片预览：

- 支持左右滑动切换。
- 支持双击放大、捏合缩放、拖动查看。
- 缩放状态下左右滑动不误触切换。

视频预览：

- 使用 16:9 优先布局。
- 竖屏下视频居中，控制条在底部。
- 横屏播放隐藏系统导航外的非必要 UI。
- 支持进度拖动、播放/暂停、全屏、音量由系统控制。

## 5. 核心页面规范

### 5.1 启动页

布局：

- 纯净背景，不显示营销内容。
- 中央显示产品名和轻量加载指示。
- 底部显示当前服务器地址或“未配置服务器”。

主要控件：

- 无常规操作按钮；只有在服务器未配置、Token 无效或启动失败时显示进入登录页的按钮。

空状态：

- 首次启动且无服务器地址时，显示“请先配置服务器地址”，主按钮“开始设置”。

加载状态：

- 读取 SecureStorage。
- 校验 Access Token 是否仍有效。
- Access Token 过期但存在 Refresh Token 时尝试刷新。
- 刷新过程中显示“正在恢复登录状态”。

错误状态：

- SecureStorage 读取失败：清理本地认证状态并进入登录页。
- Refresh Token 失效：清理本地 Token 并进入登录页。
- 服务器不可达：显示“无法连接服务器”，提供重试和切换服务器。

交互流程：

1. App 启动进入启动页。
2. 读取服务器地址和 Token。
3. 无 Token 时进入登录页。
4. Token 有效时进入 Files。
5. Token 可刷新时先刷新，再进入 Files。
6. 刷新失败时清理 Token 并进入登录页。

### 5.2 登录页

布局：

- 顶部留白后显示 PrivateCloudDrive 品牌图标、产品名和服务器地址。
- 中部为账号密码登录表单：账号、密码、登录按钮。
- 表单下方可显示微信、Google、GitHub 外部登录入口；未配置或平台不可用时隐藏或置灰。
- 底部显示服务器切换入口和版本号。

主要控件：

- 账号输入框。
- 密码输入框。
- 登录按钮。
- 外部登录按钮，作为增强能力。
- 服务器地址入口。

空状态：

- 首次打开且无服务器地址时，引导输入服务器地址。

加载状态：

- 登录按钮进入加载态。
- 禁用输入框和第三方登录按钮。

错误状态：

- 账号密码错误：显示“账号或密码不正确”。
- 服务器不可达：显示“无法连接服务器，请检查地址或网络”。
- 外部登录失败：只提示对应 provider 失败，不影响账号密码输入。
- Token 保存失败：提示“登录状态保存失败，请重试”并不进入主页。

交互流程：

1. 用户输入服务器地址，App 校验 `/.well-known/openid-configuration`。
2. 用户输入账号密码。
3. App 调用 OpenIddict Token 登录。
4. 成功后 Token 写入 SecureStorage。
5. 跳转 Files。
6. 失败时停留登录页，保留账号，清空密码。

### 5.3 文件首页

布局：

- 页头：标题“文件”、说明文案、刷新按钮。
- 位置概览卡：左侧文件夹图标，中间显示“当前位置”、当前路径和 API 地址，子目录时右侧显示返回按钮。
- 搜索筛选卡：搜索框、类型筛选、媒体筛选、排序、全局搜索开关和清除按钮。
- 操作行：上传、新建文件夹、选择。
- 内容区：文件列表默认。
- 底部导航固定。

主要控件：

## 6. 响应式与平台适配

- Android 返回键：详情页返回上级，预览页关闭预览，根 Tab 双击或再次返回才退出应用。
- iOS 安全区：顶部栏和底部导航必须避开刘海和 Home Indicator。
- 平板：底部导航可保留；文件首页可在后续演进为左侧目录树 + 右侧列表。
- 横屏：图片和视频预览优先，普通列表保持竖向信息密度。

## 7. 可访问性

- 触控区域不小于 44 x 44。
- 文本对比度满足长期阅读。
- 所有图标按钮需要语义名称。
- 错误不能只靠颜色表达，必须有文字。
- 上传进度必须有百分比文本。

## 8. 后续落地检查清单

- `Colors.xaml` 移除模板遗留的 Magenta/MidnightBlue 主导航样式，统一到本文档颜色。
- `AppShell.xaml` 登录后保持文件、媒体库、相册、上传、设置五个底部入口；回收站从设置页进入。
- 文件、媒体库、相册、上传、设置页必须使用“页头 + 状态概览卡 + 内容列表/网格”的一致结构。
- 设置页常用管理必须使用选项列表形式，不使用横向卡片。
- 文件列表、上传队列、回收站、媒体库、相册、图片预览、视频播放和设置页必须都有空、加载、错误状态。
- 分享设置、媒体处理、相册详情作为导航栈页面实现。
- Token 失效时统一跳回登录页，不能让页面进入半登录状态。
- 图片和视频缩略图必须使用后端缩略图/封面接口，不直接加载原文件。
