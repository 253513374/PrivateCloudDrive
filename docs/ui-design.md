# MAUI App 产品体验与 UI 设计规范

本文档定义 PrivateCloudDrive MAUI App 的产品体验、核心页面、设计系统和组件规范。目标是让后续 ABP 后端接口、MAUI 页面、视图模型和自动化测试可以按同一标准落地。

## 1. 设计目标

- 移动端优先，首批适配 Android 与 iOS。
- 产品形态是长期使用的文件与媒体管理工具，不做营销页、不做欢迎广告、不使用花哨渐变和装饰背景。
- 视觉参考方向是 iCloud Drive 的清晰文件层级、Google Photos 的媒体浏览效率、Cloudreve 的私有网盘任务流。
- 内容优先：文件名、缩略图、大小、时间、上传进度、回收站状态必须比装饰元素更突出。
- 界面稳定：列表、网格、底部导航、操作菜单的尺寸固定，避免加载、选择、刷新时跳动。
- 大量文件场景优先：支持快速扫描、批量选择、分页加载、错误恢复和可理解的空状态。

## 2. 信息架构

### 2.1 底部导航

MVP Core 底部导航固定 4 个入口：

| Tab | 标题 | 目标 | 默认页 |
| --- | --- | --- | --- |
| Files | 文件 | 浏览文件夹、文件和常用操作 | 文件首页 |
| Uploads | 上传 | 查看上传队列、失败重试和完成记录 | 上传队列页 |
| Trash | 回收站 | 恢复、永久删除和清空已删除文件 | 回收站页 |
| Settings | 设置 | 账号、服务器、安全和应用偏好 | 设置页 |

V1 可在底部导航增加 Photos 和 Videos：

| Tab | 标题 | 目标 | 默认页 |
| --- | --- | --- | --- |
| Photos | 图片 | 以时间和缩略图浏览图片 | 图片网格页 |
| Videos | 视频 | 浏览视频封面、时长和播放入口 | 视频列表页 |

交互规则：

- 未登录时只显示启动页或登录页，不显示底部导航。
- 登录后默认进入 Files。
- Uploads 有进行中或失败任务时显示角标，角标只显示数量或失败点，不显示长文本。
- 详情、预览、播放页作为导航栈页面打开，不占用底部导航入口。
- 分享设置页属于 V1，作为导航栈页面打开。

### 2.2 顶部栏

顶部栏高度 52 到 56。移动端左侧为页面标题或返回按钮，中间不放装饰性 Logo，右侧为搜索、排序、视图切换或更多操作。

页面标题规则：

- 文件首页显示当前目录名，根目录显示“文件”。
- 上传页显示“上传”。
- 回收站页显示“回收站”。
- 设置页显示“设置”。
- 图片页显示“图片”，V1。
- 视频页显示“视频”，V1。

### 2.3 操作层级

- 高频操作使用顶部图标按钮或页面内主按钮：上传、新建文件夹、刷新、搜索。
- 中频操作放入列表项滑动操作或底部操作菜单：删除、恢复、下载、详情。
- 重命名、移动、分享、收藏、标签属于 V1 操作。
- 高风险操作必须二次确认：删除、永久删除、取消分享、解绑微信、退出登录。

## 3. 设计系统

### 3.1 颜色

整体以中性灰、白色、少量绿色主色和状态色组成。避免大面积单一绿色、紫色、蓝紫渐变、米色或深蓝背景。

| Token | 浅色模式 | 深色模式 | 用途 |
| --- | --- | --- | --- |
| `Color.Background` | `#F7F9FC` | `#0F1720` | 页面背景 |
| `Color.Surface` | `#FFFFFF` | `#161F2A` | 列表、底部导航、菜单 |
| `Color.SurfaceAlt` | `#F1F5F9` | `#1F2937` | 搜索框、筛选条、上传行背景 |
| `Color.TextPrimary` | `#17202A` | `#F8FAFC` | 主文本 |
| `Color.TextSecondary` | `#607083` | `#B6C2CF` | 元数据、说明 |
| `Color.TextTertiary` | `#8A98A8` | `#7C8896` | 占位、禁用 |
| `Color.Border` | `#E2E8F0` | `#2D3748` | 分割线、边框 |
| `Color.Primary` | `#1F7A5C` | `#7EC9B0` | 主按钮、选中状态 |
| `Color.PrimarySoft` | `#D8EFE7` | `#183E34` | 选中背景、轻提示 |
| `Color.Info` | `#275B89` | `#7BA7D8` | 链接、信息 |
| `Color.Warning` | `#B76E00` | `#F5B45B` | 暂停、容量接近上限 |
| `Color.Danger` | `#B42318` | `#FF8A80` | 错误、删除 |
| `Color.Success` | `#15803D` | `#86D99A` | 上传完成、保存成功 |

落地要求：

- 主色只用于可交互重点，不用于大面积背景。
- 删除、解绑、清空队列等危险操作统一使用 `Danger`。
- 缩略图加载失败时使用 `SurfaceAlt` 背景加文件类型图标，不使用醒目色块。
- 深色模式不使用纯黑作为普通页面背景，视频和图片预览页例外。

### 3.2 字体

默认使用 MAUI 项目已有 OpenSans，平台字体不可用时回退系统字体。

| 层级 | 字号 | 字重 | 行高 | 用途 |
| --- | --- | --- | --- | --- |
| PageTitle | 22 | Semibold | 28 | 页面标题 |
| SectionTitle | 17 | Semibold | 24 | 分组标题 |
| Body | 15 | Regular | 22 | 文件名、正文 |
| BodyStrong | 15 | Semibold | 22 | 重要文件名、用户名 |
| Meta | 13 | Regular | 18 | 大小、时间、路径 |
| Caption | 12 | Regular | 16 | 状态、角标、辅助信息 |
| Button | 15 | Semibold | 20 | 按钮文本 |

文本规则：

- 不使用随屏幕宽度变化的字体。
- 文件名最多两行，第二行截断；列表模式默认一行截断。
- 按钮文本必须完整显示，短按钮优先使用图标。
- 中文、英文、数字混排时不使用负字距。

### 3.3 间距与布局

- 基础间距单位为 4。
- 页面左右边距：手机 16，平板 24。
- 列表项内边距：水平 16，垂直 10 到 12。
- 图标与文本间距：8。
- 分组标题上边距：20，下边距：8。
- 底部导航高度：60 到 64，需避开安全区。
- 触控目标最小 44 x 44。

### 3.4 圆角与边框

- 主按钮、输入框、搜索框、文件卡片：8。
- 缩略图：6。
- 小标签、状态胶囊：6。
- 列表项默认无卡片边框，以分割线和留白区分。
- 不做卡片套卡片。

### 3.5 图标

图标风格使用线性、单色、24px 主尺寸。实现建议使用 `FontImageSource` 绑定统一图标字体，避免每个页面手写 SVG。

核心图标语义：

- 文件夹：folder
- 图片：image
- 视频：video
- 上传：upload
- 下载：download
- 更多：more-horizontal
- 搜索：search
- 排序：arrow-up-down
- 视图切换：list / grid
- 删除：trash
- 回收站：archive-restore
- 恢复：rotate-ccw
- 设置：settings
- 播放：play
- 暂停：pause
- 重试：refresh-cw
- 分享：share，V1
- 收藏：star，V1
- 标签：tag，V1

状态规则：

- 未选中图标使用 `TextSecondary`。
- 选中图标使用 `Primary`。
- 禁用图标使用 `TextTertiary`。
- 危险操作图标使用 `Danger`。

## 4. 组件规范

### 4.1 按钮

| 类型 | 样式 | 用途 |
| --- | --- | --- |
| Primary | 主色背景、白色文本、8 圆角 | 登录、保存、确认上传 |
| Secondary | `SurfaceAlt` 背景、主文本 | 取消、选择目标目录 |
| Text | 透明背景、主色文本 | 次要链接 |
| Icon | 44 x 44，透明或浅背景 | 搜索、排序、更多 |
| Danger | 透明或浅红背景、红色文本 | 删除、解绑、退出 |

规则：

- 一个页面同一层级最多一个 Primary。
- 表单底部按钮固定顺序：取消在左，确认在右。
- 加载中按钮禁用并显示小型 ActivityIndicator。

### 4.2 输入框

- 高度 44 到 48。
- 背景 `SurfaceAlt`，边框 `Border`。
- 聚焦边框 `Primary`。
- 错误文本显示在输入框下方，字号 12，颜色 `Danger`。
- 密码框必须有显示/隐藏图标。

### 4.3 文件列表项

列表项高度 64 到 72。

内容结构：

- 左侧：44 x 44 图标或缩略图。
- 中间：文件名一行，元数据一行。
- 右侧：状态图标或更多按钮；收藏图标属于 V1。

元数据格式：

- 文件夹：`12 项 · 2026-05-07`
- 文件：`24.8 MB · 2026-05-07`
- 图片：`4032 x 3024 · 3.2 MB`
- 视频：`12:34 · 1920 x 1080 · 128 MB`

滑动操作：

- MVP Core 左滑显示删除。
- V1 左滑增加分享、重命名、移动。
- 删除必须二次确认。
- 批量选择时禁用滑动操作，底部显示批量操作栏。

### 4.4 文件卡片

网格文件卡片用于文件首页的网格模式。

- 手机两列或三列，按屏宽决定。
- 卡片不使用阴影。
- 缩略图区域固定 1:1。
- 文件名显示在缩略图下方，最多两行。
- 文件夹卡片使用浅底和文件夹图标，不使用大面积高饱和颜色。

### 4.5 缩略图比例

| 类型 | 比例 | 说明 |
| --- | --- | --- |
| 图片网格 | 1:1 | 裁切填充，预览页显示完整图 |
| 视频封面 | 16:9 | 右下角显示时长 |
| 文件图标 | 1:1 | 图标居中 |
| 分享预览 | 16:9 或 1:1 | V1，根据首个媒体类型决定 |

加载策略：

- 先显示骨架块，再显示缩略图。
- 缩略图失败时显示类型图标和“无法加载缩略图”短提示。
- 不直接在列表中加载图片原图。

### 4.6 底部导航

- 高度 60 到 64。
- 图标 22 到 24，文本 11 到 12。
- 当前 Tab 使用主色，未选中使用 `TextSecondary`。
- 上传角标使用 `Danger` 表示失败，使用 `Primary` 表示进行中数量。

### 4.7 操作菜单

移动端使用底部菜单。菜单项高度 48。

排序：

1. 主要动作：打开、播放、预览。
2. 管理动作：详情、下载、恢复。
3. V1 管理动作：重命名、移动、标签、收藏。
4. V1 分享动作：分享、复制链接。
5. 危险动作：删除、永久删除、取消分享、解绑。

危险动作放在最后，并用 `Danger`。

### 4.8 上传进度组件

上传队列项高度 76 到 88。

内容：

- 文件名。
- 目标目录。
- 进度条，高度 4。
- 进度文案：`45% · 2.1 MB/s · 剩余 01:23`。
- 状态按钮：暂停、继续、取消、重试。

状态：

- Waiting：灰色进度条，显示“等待上传”。
- Uploading：主色进度条。
- Paused：警告色，显示“已暂停”。
- Failed：红色，显示错误摘要和重试按钮。
- Completed：成功色，2 秒后可折叠到完成记录。

### 4.9 媒体预览组件

图片和视频预览页允许使用黑色背景，因为内容本身需要沉浸展示。

通用规则：

- 顶部工具栏默认半透明，轻触隐藏或显示。
- 底部操作栏包含详情、下载；收藏和分享属于 V1。
- 错误状态必须保留返回按钮。

图片预览：

- 支持左右滑动切换。
- 支持双击放大、捏合缩放、拖动查看。
- 缩放状态下左右滑动不误触切换。

视频预览：

- 使用 16:9 优先布局。
- 竖屏下视频居中，控制条在底部。
- 横屏播放隐藏系统导航外的非必要 UI。
- 支持进度拖动、播放/暂停、全屏、音量由系统控制。

## 5. 核心页面规范

### 5.1 启动页

布局：

- 纯净背景，不显示营销内容。
- 中央显示产品名和轻量加载指示。
- 底部显示当前服务器地址或“未配置服务器”。

主要控件：

- 无常规操作按钮；只有在服务器未配置、Token 无效或启动失败时显示进入登录页的按钮。

空状态：

- 首次启动且无服务器地址时，显示“请先配置服务器地址”，主按钮“开始设置”。

加载状态：

- 读取 SecureStorage。
- 校验 Access Token 是否仍有效。
- Access Token 过期但存在 Refresh Token 时尝试刷新。
- 刷新过程中显示“正在恢复登录状态”。

错误状态：

- SecureStorage 读取失败：清理本地认证状态并进入登录页。
- Refresh Token 失效：清理本地 Token 并进入登录页。
- 服务器不可达：显示“无法连接服务器”，提供重试和切换服务器。

交互流程：

1. App 启动进入启动页。
2. 读取服务器地址和 Token。
3. 无 Token 时进入登录页。
4. Token 有效时进入 Files。
5. Token 可刷新时先刷新，再进入 Files。
6. 刷新失败时清理 Token 并进入登录页。

### 5.2 登录页

布局：

- 顶部留白后显示产品名 `PrivateCloudDrive` 和服务器地址。
- 中部为账号密码登录表单：账号、密码、登录按钮。
- 表单下方可在 V1 显示微信登录按钮；未配置或平台不可用时隐藏。
- 底部显示服务器切换入口和版本号。

主要控件：

- 账号输入框。
- 密码输入框。
- 登录按钮。
- 微信登录按钮，V1 可选。
- 服务器地址入口。

空状态：

- 首次打开且无服务器地址时，引导输入服务器地址。

加载状态：

- 登录按钮进入加载态。
- 禁用输入框和第三方登录按钮。

错误状态：

- 账号密码错误：显示“账号或密码不正确”。
- 服务器不可达：显示“无法连接服务器，请检查地址或网络”。
- 微信登录失败，V1：只提示微信失败，不影响账号密码输入。
- Token 保存失败：提示“登录状态保存失败，请重试”并不进入主页。

交互流程：

1. 用户输入服务器地址，App 校验 `/.well-known/openid-configuration`。
2. 用户输入账号密码。
3. App 调用 OpenIddict Token 登录。
4. 成功后 Token 写入 SecureStorage。
5. 跳转 Files。
6. 失败时停留登录页，保留账号，清空密码。

### 5.3 文件首页

布局：

- 顶部栏：当前目录名、搜索、排序、视图切换、更多。
- 面包屑或路径条：根目录、上级目录、当前目录。
- 内容区：列表模式默认，用户可切换网格。
- 右下角浮动操作按钮：上传。
- 底部导航固定。

主要控件：

- 搜索入口。
- 排序菜单：名称、时间、大小、类型。
- 列表/网格切换。
- 新建文件夹。
- 上传文件。
- 下拉刷新。
- 分页加载。

空状态：

- 当前文件夹为空：显示小文件夹图标、文案“这里还没有文件”，主按钮“上传文件”，次按钮“新建文件夹”。
- 搜索无结果：显示“没有匹配的文件”并提供清除筛选。

加载状态：

- 首屏使用 8 到 12 条骨架列表。
- 分页加载在列表底部显示小型加载指示。

错误状态：

- 目录加载失败显示内联错误块和重试按钮。
- 权限不足显示“没有权限访问此目录”并返回上级入口。

交互流程：

- 点击文件夹进入子目录。
- 点击图片进入图片预览。
- 点击视频进入视频播放。
- 点击普通文件进入文件详情。
- 长按进入选择模式。
- 选择模式下底部显示批量操作栏：下载、删除、更多。
- V1 选择模式增加移动、标签、收藏、分享。

### 5.4 图片网格页，V1 独立媒体库入口

布局：

- 顶部栏：标题“图片”、搜索、排序、筛选。
- 时间分组标题：今天、本周、月份。
- 网格：手机 3 列，平板 4 到 6 列。
- 图片缩略图 1:1，无卡片边框。

主要控件：

- 时间排序。
- 标签筛选，仅在标签模块启用后显示。
- 收藏筛选，仅在收藏模块启用后显示。
- 多选。

空状态：

- 没有图片：显示图片图标和“上传图片后会在这里显示”。

加载状态：

- 方形骨架网格。
- 分组标题先出现时，缩略图可逐步加载。

错误状态：

- 缩略图失败：单格显示占位图标。
- 列表失败：页面内错误块和重试按钮。

交互流程：

- 点击图片进入图片预览。
- 长按图片进入选择模式。
- 选择模式下支持下载、删除。
- 收藏、分享属于 V1 操作。

### 5.5 视频列表页，V1 独立媒体库入口

布局：

- 顶部栏：标题“视频”、搜索、排序、筛选。
- 默认列表：左侧 128 x 72 封面，右侧标题、时长、大小、时间。
- 平板可切换 2 列卡片。

主要控件：

- 按时间、大小、时长排序。
- 收藏筛选，仅在收藏模块启用后显示。
- 标签筛选，仅在标签模块启用后显示。
- 更多操作。

空状态：

- 没有视频：显示视频图标和“上传视频后会在这里显示”。

加载状态：

- 16:9 封面骨架和两行文本骨架。

错误状态：

- 封面未生成：显示视频图标和“处理中”。
- 封面失败：显示“封面生成失败”，仍可播放原视频。

交互流程：

- 点击列表项进入视频播放页。

## 6. 响应式与平台适配

- Android 返回键：详情页返回上级，预览页关闭预览，根 Tab 双击或再次返回才退出应用。
- iOS 安全区：顶部栏和底部导航必须避开刘海和 Home Indicator。
- 平板：底部导航可保留；文件首页可在后续演进为左侧目录树 + 右侧列表。
- 横屏：图片和视频预览优先，普通列表保持竖向信息密度。

## 7. 可访问性

- 触控区域不小于 44 x 44。
- 文本对比度满足长期阅读。
- 所有图标按钮需要语义名称。
- 错误不能只靠颜色表达，必须有文字。
- 上传进度必须有百分比文本。

## 8. 后续落地检查清单

- `Colors.xaml` 移除模板遗留的 Magenta/MidnightBlue 主导航样式，统一到本文档颜色。
- `AppShell.xaml` 改为启动/登录外壳 + 登录后 MVP Core 底部导航结构。
- 文件列表、上传队列、回收站、图片预览、视频播放和设置页必须都有空、加载、错误状态。
- 图片网格、视频列表、分享设置页作为 V1 页面实现。
- Token 失效时统一跳回登录页，不能让页面进入半登录状态。
- 图片和视频缩略图必须使用后端缩略图/封面接口，不直接加载原文件。
