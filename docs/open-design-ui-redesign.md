# PrivateCloudDrive Open Design UI Redesign

日期：2026-05-17
负责人：Hermes 产品总监 / Claude Design 模式
输入：用户提供的 Open Design 移动端参考图两张
输出：产品 UI 视觉方向、页面结构、组件系统与工程落地规则

---

## 1. 设计总监结论

本轮采用 Open Design 方向，允许 PrivateCloudDrive 从原先“保守工具型界面”升级为“暗色、沉浸、内容优先、带少量智能感的私有云盘”。

但该方向必须被产品化，而不是简单照搬参考图中的大渐变和 AI 感：

- 可以采用深色基底、蓝紫主操作、毛玻璃底栏、媒体卡片、容量概览、侧边抽屉。
- 可以引入“智能相册 / AI 记忆 / OCR / 自动备份”的未来入口，但近期必须标注为 Coming Soon 或隐藏在探索区。
- 文件页仍必须保留文件名、大小、时间、同步状态、服务状态等可信信息。
- 不允许为了视觉酷感牺牲私有部署产品的安全感、可诊断性和文件管理效率。

一句话方向：

> Open Design for PrivateCloudDrive = 暗色专业工具 + 媒体级沉浸体验 + 私有部署可信状态 + 渐进式 AI 入口。

## 2. 从参考图提炼的视觉语言

### 2.1 整体气质

| 维度 | 参考图表现 | PrivateCloudDrive 落地规则 |
|---|---|---|
| 背景 | 深蓝黑、微弱光晕 | 使用暗色原生背景，不用纯黑；允许轻微径向光晕 |
| 字体 | 大标题、强数字、白色高对比 | 标题可更大，但文件列表仍保持扫描效率 |
| 色彩 | 蓝紫渐变、亮蓝选中态、绿色/粉色视频缩略图 | 主色采用蓝紫；内容缩略图可多彩，系统 chrome 保持克制 |
| 卡片 | 半透明深色卡片、细边框 | 统一为 OpenCard，避免卡片套卡片 |
| 导航 | 毛玻璃底栏 + 中央加号 | 可作为新版 App Shell 方向 |
| 菜单 | 右侧/侧边抽屉，分组列表 | 设置/我的/管理入口采用分组抽屉或 Me 页面 |
| 媒体 | 大型精选卡 + 三列缩略图 | 相册/媒体库主页面优先采用该结构 |
| 存储 | 环形容量图 + 分类列表 | V1.3 存储页应采用该模型 |

## 3. 新产品信息架构

参考图的底部导航是：文件 / 相册 / + / 动态 / 我的。

结合 PrivateCloudDrive 当前能力，建议新版 App Shell：

| Tab | 标题 | 定位 | 说明 |
|---|---|---|---|
| Files | 文件 | 核心文件管理 | 所有文件、最近、收藏、分享、回收站入口 |
| Photos | 相册 | 媒体时间线与相册 | 图片/视频时间线、智能相册、AI 记忆入口 |
| Create | + | 全局创建/上传动作 | 拍照、从相册选择、本机文件、扫描文档、新建文件夹、链接导入 |
| Activity | 动态 | 传输与任务状态 | 上传、下载、自动备份、媒体处理、同步失败 |
| Me | 我的 | 账号、安全、容量、设备 | 个人资料、容量、设备、登录历史、设置、管理后台入口 |

关键调整：

- 不再把“上传”作为普通 Tab，而是升级为中央 `+` Action Sheet。
- “上传队列”进入 `动态`，承担任务中心职责。
- “设置”升级为 `我的`，让账号、容量、安全、设备更符合移动产品心智。
- 分享、回收站、设备、日志从 Me/抽屉进入，不作为底部主 Tab。

### 4.2 渐变规则

允许：

- 头像渐变：蓝 -> 紫。
- 主按钮：蓝 -> 紫。
- 媒体精选卡：按内容生成柔和渐变。
- 容量图、分类图：使用语义分类色。

不允许：

- 整页大面积彩虹渐变。
- 每个卡片都使用不同强渐变。
- 文件管理列表背景使用图片级渐变。

### 4.3 字体层级

| 层级 | 字号 | 字重 | 用途 |

| SectionTitle | 15-17 | 700 | 分组标题 |

## 5. 页面级设计

### 5.1 文件首页

目标：把“我的云盘”设计成可信、高效、带容量状态的文件入口。

结构：

1. 顶部：菜单、问候语、通知、头像。
2. 搜索框：搜索文件、人、地点；右侧扫描/筛选入口。
3. 存储概览卡：已用容量、总容量、文件数量、同步状态、分类进度条。
4. 快速访问：最近、收藏、我的分享、离线文件。
5. 文件夹网格：照片、工作文档、电影、家庭备份、设计资源等。
6. 最近文件列表：缩略图、文件名、大小、时间、更多。
7. Floating Bottom Nav。

验收标准：

- 首屏能看见容量、同步状态、搜索、核心文件夹。
- 文件夹卡片不少于 44px 触控区，标题和数量不截断。
- 最近文件必须显示大小和时间。

### 5.2 上传 Action Sheet

目标：中央 `+` 不是页面，而是全局创建/上传动作入口。

动作列表：

- 拍照：使用相机拍摄并上传。
- 从相册选择：批量选择图片/视频。
- 本机文件：选择 App 内/系统文件。
- 扫描文档：拍照 + OCR，V2 可用；V1.3 可灰显。
- 新建文件夹：在当前位置创建。
- 从链接导入：V2/探索。

规则：

- Action Sheet 背景半透明深色，底部弹出。
- 背后页面加 blur/dim。
- 每行包含彩色语义图标、标题、说明、右箭头。
- 取消按钮独立置底。

### 5.3 相册/媒体首页

目标：借鉴参考图“我的记忆”，让媒体库从文件列表升级为内容回看体验。

结构：

1. 标题：我的记忆 · 媒体数量。
2. 右侧：搜索、AI/处理状态。
3. 分段筛选：时刻、人物、地点、记忆。
4. AI 精选记忆大卡：地点、日期、照片数量、播放入口。
5. 时间线分组：今天/地点/月份。
6. 三列媒体缩略图，视频显示时长，多图集合显示数量。
7. 处理状态小条：仅在有任务时出现。

近期落地：

- 可以先用“媒体库”现有图片/视频数据填充。
- 人物、地点、AI 记忆可以作为隐藏/灰显/Coming Soon，不阻塞 V1.2。

### 5.4 智能相册/人物页

目标：为 V2/V3 保留可扩展结构，不提前承诺 AI 已可用。

结构：

- 筛选：时刻 / 人物 / 地点 / 记忆。
- 人物圆形封面网格。
- 添加人物虚线圆形入口。
- 底部 AI 处理状态卡，仅当索引任务存在时展示。

规则：

- 如果 AI 未启用，页面显示“智能整理未启用”，并提供了解/设置入口。
- 不展示假人物、假识别数据。

### 5.5 AI 记忆页

目标：展示自动生成的回忆集合；属于 V3 或体验探索。

结构：

- 大卡列表，每张卡含渐变封面、标题、副标题、播放按钮。
- 胶囊标识：AI 记忆、AI 洞察。
- 不作为 V1.2/V1.3 交付承诺。

### 5.6 我的 / 账号页

目标：把设置页升级成用户和私有云状态中心。

结构：

1. 顶部：标题“我的”、设置按钮。
2. 用户卡：头像、用户名、邮箱/服务账号、角色、编辑按钮。
3. 个人云盘容量进度条。
4. 快速数字：文件数、照片数、设备数。
5. 账号与安全：个人资料、账号安全、登录设备、安全与操作日志。
6. 同步与备份：自动备份开关、相册同步、备份状态。
7. 其他：回收站、设备、设置、退出登录。

验收标准：

- 用户能在 3 秒内找到容量、设备、安全、回收站。
- 退出登录和危险操作不混在普通分组中。

### 5.7 存储用量页

目标：让用户清楚知道空间被谁占用、是否需要清理、还能用多久。

结构：

1. 顶部返回 + 标题。
2. 环形容量图：已用百分比、已用/总量、升级/扩容入口可隐藏。
3. 分类明细：照片、视频、文档、音频、应用备份、其他、可用。
4. AI 清理建议：重复照片、大型视频、临时文件等；V2 可用。
5. 管理动作：查看大文件、清理回收站、备份策略。

V1.3 优先落地：

- 容量图。
- 分类明细。
- 回收站清理入口。
- 大文件入口可后置。

### 5.8 侧边菜单 / 抽屉

目标：提供跨模块导航，但不抢占底部主路径。

分组：

- 文件：全部文件、最近、收藏夹、我的分享、离线文件。
- 协作：共享给我、团队空间。
- 智能：智能相册、自动备份、文档 OCR。
- 其他：回收站、设备、设置。

规则：

- 当前页面高亮蓝色背景。
- 每项右侧显示数量。
- 底部显示节点/服务状态，例如：主节点 · 杭州 · v2.4.1。

## 7. 工程落地顺序

### Phase A：设计系统与 App Shell

1. 增加 Open Design tokens：颜色、圆角、间距、字体层级。
2. 把底部导航文案调整为：文件 / 相册 / + / 动态 / 我的。
3. 中央 `+` 先实现为全局上传 Action Sheet。
4. 保留旧页面 ViewModel，不做业务重写。

### Phase B：文件首页

1. 新增搜索框。
2. 新增容量概览卡。
3. 文件夹网格改为 Open FolderTile。
4. 最近文件列表改为深色 OpenListItem。

### Phase C：媒体/相册

1. 合并图片/视频心智为“相册/媒体”。
2. 新增 AI 精选记忆卡，但数据来自现有媒体分组。
3. 三列媒体网格优化为参考图结构。

### Phase D：我的与存储页

1. 设置页升级为我的页。
2. 增加容量、设备、安全、回收站入口。
3. 增加存储用量页。

### Phase E：动态/任务中心

1. 上传队列迁移到动态。
2. 媒体处理、备份、同步失败统一进入动态。
3. 有任务时显示角标，无任务时保持安静。

## 8. 明确不做

近期不做：

- 不承诺真正人脸识别。
- 不承诺 AI 自动生成记忆。
- 不承诺端到端加密 UI 完整闭环。
- 不承诺 Office 协作。
- 不把 NAS OS、Docker、磁盘阵列作为移动端主导航。

允许展示但必须标注为探索或隐藏：

- 智能相册。
- 文档 OCR。
- 自动备份增强。
- AI 清理建议。

## 9. 验收标准

视觉验收：

- 主页面为暗色原生，不出现浅色/绿色旧风格混杂。
- 选中态、主按钮、加号统一使用蓝紫主色。
- 容量卡、文件夹卡、媒体卡、设置组使用一致半透明卡片语言。
- 底部导航可读、触控足够、中央加号明显但不遮挡内容。

产品验收：

- 文件首页仍能完成浏览、搜索、上传、预览、删除主链路。
- 我的页能进入回收站、设备、设置、操作日志/安全日志。
- 存储用量能展示容量、分类、可用空间。
- 上传 Action Sheet 能触发已有上传能力，不因为视觉重构破坏文件选择。

工程验收：

```bash
dotnet build maui/PrivateCloudDrive.App/PrivateCloudDrive.App.csproj -f net10.0-android -c Debug -p:EmbedAssembliesIntoApk=true -p:AndroidFastDeploymentType=None
```

Android 验收：

- clean install 最新 Debug APK。
- 启动 App。
- 登录或进入已登录状态。
- 截图验证：文件、相册、动态、我的、上传 Action Sheet、存储用量页。
