# 设置页趋势化重设计草图

## 参考趋势

参考文章：[2026年UI设计这10个变化，80%的设计师还没反应过来](https://mp.weixin.qq.com/s/0gLZ1j6GlPlo_f2cfBvmag)。

文章核心判断是 UI 从静态展示转向会响应上下文的系统。对 PrivateCloudDrive 设置页，适合吸收的趋势是：

- 界面要有材质和层次，但不做重装饰。用柔和分层、轻阴影和半透明感表达“私有云空间”，而不是堆卡片。
- AI 或智能化不一定作为按钮出现。当前项目暂不引入 AI，可先把“建议清理回收站”“容量风险”“会话状态”做成上下文提示。
- 个性化从固定页面变成即时状态。设置页顶部根据登录、容量、服务连通性展示不同主提示。
- 动效服务于反馈。加载、绑定、解绑、重试用小范围状态变化，不做炫技转场。
- 安静界面成为优势。设置页应降低信息噪声，把常用入口和危险操作清楚分层。
- 仪表盘式堆数据让位给故事界面。设置页按“账号是否正常 -> 空间是否够用 -> 去哪里管理 -> 登录方式是否完整 -> 如何排障/退出”的顺序组织。
- 不完美可以成为信任感。私有部署场景应明确显示本机服务地址、版本、当前状态，而不是隐藏技术细节。

## 设计目标

设置页不做控制台。它应回答用户打开页面后的几个直接问题：

- 当前是哪一个账号、连到哪台私有云。
- 空间是否紧张，需要做什么。
- 回收站、分享、日志在哪里。
- 微信、Google、GitHub 是否可用或已绑定。
- 本机安全状态、服务地址、版本信息是否正常。
- 如何安全退出。

## 草图结构

视觉草图：`docs/assets/design/settings-page-trend-sketch.svg`

页面层级：

1. 顶部状态层
   - 标题：设置
   - 账号概览：头像、用户名、已登录状态、服务名称。
   - 环境提示：当前服务地址，异常时改为“无法连接服务端”。

2. 存储故事卡
   - 主数字：已用容量 / 总容量。
   - 进度条：正常为主色，接近上限时换为警示色。
   - 上下文行动：空间紧张时展示“清理回收站”；正常时展示“查看回收站”。

3. 常用管理入口
   - 回收站：查看已删除文件。
   - 我的分享：管理分享链接。
   - 操作日志：查看登录、上传、删除记录。
   - 媒体处理：作为 V1.2 预留入口，可先隐藏或禁用。
   - 呈现方式使用设置页选项列表，不使用横向卡片；每行左侧标题和说明，右侧箭头或状态。

4. 登录方式
   - 微信、Google、GitHub 合并为同一组列表项。
   - 每项右侧只显示一个主要状态：已绑定、绑定、未启用、不可用、检查中。
   - 解绑仍然二次确认。

5. 服务与安全
   - 本地会话受保护。
   - 服务地址、App 版本、服务端版本。
   - 这里保留私有部署透明度，不隐藏排障信息。

6. 危险操作
   - 退出登录独立置底，使用危险色弱背景。
   - 保留确认弹窗，不删除云端文件。

## 映射到现有代码

- `SettingsStatePanel` 不再作为单独卡片长期占位，建议并入顶部账号概览下方的内联状态条。
- `StorageUsageLabel`、`StorageProgressBar`、`StorageQuotaLabel` 继续保留，但从普通卡片提升为页面核心卡。
- `OnTrashClicked`、`OnSharesClicked`、`OnOperationLogsClicked` 保持现有路由不变，只调整入口呈现。
- 微信、Google、GitHub 绑定逻辑保持现有方法和按钮状态，只把三个独立卡片合并为一个“登录方式”分组。
- `ApiBaseUrl` 继续显示，但从首屏普通卡片移到账号概览和服务信息中各出现一次：首屏短地址，底部完整地址。

## 实现注意

- MAUI 不要依赖真实系统级 blur。用浅色半透明感、边框、轻阴影、主色软背景模拟材质即可。
- 保持 8px 圆角体系；顶部主卡可使用 12px 以内圆角，但不要扩散成过度圆润风格。
- 所有入口触控区域至少 44px。
- 错误状态必须有文字，不只靠颜色。
- 账号密码登录仍然是主路径，外部登录只做增强能力。
