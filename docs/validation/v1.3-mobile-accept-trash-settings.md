### AC1/AC2 阻挡详情

**缺陷 #1 — 回收站 API 路由不匹配（Blocking P1-06）**

- **复现步骤**: 用户打开 TrashPage，`LoadTrashStorageSummaryAsync` 被调用
- **前端调用**: `GET /api/file-center/trash/storage-summary`（CloudDriveApiClient.cs L1208）
- **后端实际路由**: `[HttpGet("cleanup-advice")]` → `GET /api/file-center/trash/cleanup-advice`（FileCenterTrashController.cs L53）
- **预期结果**: HTTP 200，返回 TrashCleanupAdviceDto JSON
- **实际结果**: HTTP 404，被 `LoadTrashStorageSummaryAsync` catch 捕获，展示"无法读取"和"回收站存储信息暂时不可用"
- **影响范围**: P1-06 全部功能无法使用
- **严重级别**: **P0 — 该功能核心链路断裂**

**缺陷 #2 — DTO 属性名不匹配（即使路由修复也无法正常解析）**

- **后端 DTO `TrashCleanupAdviceDto`**: `TrashSizeBytes`, `AutoCleanupCount`, `CleanupAdviceMessage`, `RetentionDays`
- **前端 DTO `TrashStorageSummaryDto`**: `UsedBytes`, `ItemsOverThresholdCount`, `CleanupSuggestion`, `RetentionDays`
- **影响**: 即使路由修复，JSON 反序列化也无法正确映射（不同属性名），`UsedBytes`/`ItemsOverThresholdCount`/`CleanupSuggestion` 均为 0/空字符串
- **严重级别**: P1 — 连带缺陷，必须同步修复
