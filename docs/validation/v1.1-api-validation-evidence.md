### 1.2 弱网/超时处理逻辑

```
用户操作 → HTTP 请求
  ├── 网络断开 → HttpRequestException → UserVisibleErrorSanitizer
  │   └── 用户可见: "无法连接到私有服务器。请确认后端服务和网络恢复后，点击'重试备份'。"
  ├── 请求超时(15s) → TaskCanceledException → UserVisibleErrorSanitizer
  │   └── 用户可见: "备份请求超时。请确认网络稳定或服务器恢复后，点击'重试备份'。"
  ├── 401/Unauthorized → AuthSessionExpiredException → 引导重新登录
  ├── 500/ServiceUnavailable → ABP 错误解析 → InvalidOperationException(服务器错误消息)
  └── 2xx → 正常返回
```

```

  → CreateUploadSessionAsync (POST /api/file-center/upload-sessions)

```

  ├── 单文件操作
