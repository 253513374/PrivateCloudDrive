## 一、P1-03：媒体任务页 (MediaProcessingStatusPage)

### AC 覆盖总表

| # | 验收标准 | 状态 | 证据 |
|---|---------|------|------|
| AC1 | 管理员查看媒体处理任务列表 | ⚠️ 有条件通过 | API 层存在且 4 状态均受支持；MAUI 页无管理员独立入口 |
| AC2 | 支持 4 种状态筛选 (Pending/Processing/Completed/Failed) | ✅ 通过 | 后端 `GetMediaProcessingStatusInput.Status` + XAML 5 个分段按钮 |
| AC3 | 失败任务展示失败原因 | ✅ 通过 | DTO `ProcessErrorSummary` 字段 → `StatusDetailText` 绑定 |
| AC4 | 管理员触发重新处理 | ✅ 通过 | Router `retry-processing` POST + `OnRetryProcessingClicked` 按钮 |
| AC5 | 展示处理队列积压情况 | ✅ 通过 | `ItemCountText` 显示 "{N} 项待处理媒体" |

### AC1 详细分析：管理员权限边界

- **后端 `MediaTasksController`** (`api/admin/media-tasks`): 需要 `FileCenter.Manage` 权限，支持 `GET`（分页列表）+ `POST {mediaAssetId}/retry`。
- **MAUI 端调用**: 当前 `MediaProcessingStatusPage` 是通过 `ICloudDriveApiClient.GetMediaProcessingItemsAsync()` 调用 `/api/file-center/media/processing-status`（普通用户端），该端点只需要 `FileCenter.View` 权限，返回 `PagedResultDto<MediaTimelineItemDto>`。
- **结论**: 普通用户可查看自己的媒体处理状态，管理员可通过 admin API 查看全局队列。MAUI 页没有独立的 admin 入口（只能从 PhotosPage/SettingsPage 进入），属于合理设计。但 AC 要求"管理员可查看"没有独立的 admin 视图入口，标记为"有条件通过"。

### AC3 失败原因展示验证

后端的 `MediaTimelineItemDto` 包含 `ProcessErrorSummary` 字段，MAUI 端 `MediaLibraryItem.StatusDetailText` 属性拼接了 `ProcessStatusText + ProcessErrorSummary`，失败原因展示链条完整。

### AC4 重新处理验证

- 后端: `POST /api/file-center/media/{fileNodeId}/retry-processing` 需要 `FileCenter.Manage` 权限
- MAUI 端: `MediaProcessingStatusPage.xaml` 中每个 Failed 状态的 item 显示"重试"按钮，绑定 `OnRetryProcessingClicked` 事件
- 权限检查: 普通用户在 `GetMediaProcessingItemsAsync` 后能看见"重试"按钮但 API 会返回 403，属于合理的安全设计

### AC5 队列积压情况

- `MediaProcessingStatusPage.xaml` 顶部显示 `ItemCountText`，格式为 `{N} 项待处理媒体`
- 使用 `CollectionView` 展示列表，支持空状态展示

### 🔴 P0 缺陷：分享风险 API 前后端不连通

**复现步骤**:
1. 从 MAUI App 的 SettingsPage 导航到 ShareRiskPage
2. 页面调用 `ICloudDriveApiClient.GetShareRiskSummaryAsync()`
3. 该方法发送 `GET /api/file-center/shares/risk-summary`

**预期结果**: API 返回分享风险数据，页面展示数量及文案

**实际结果**:
1. **URL 路径不匹配**:
   - MAUI Client 调用: `GET /api/file-center/shares/risk-summary`
   - 后端实际路由: `GET /api/file-center/shares/risk`
   - 后端无 `/risk-summary` 端点 → 返回 404

2. **DTO 属性名不匹配**（即使 URL 正确，也会反序列化失败）:

   | 后端 `ShareRiskDto` | MAUI `ShareRiskSummaryDto` |
   |---|---|
   | `NoExpirationCount` | `NoExpiryShareCount` |
   | `PublicNoPasswordCount` | `PublicShareCount` |
   | `LongUnusedCount` | `LongUnusedShareCount` |
   | `NoExpirationMessage` | `NoExpiryWarning` |
   | `PublicShareMessage` | `PublicWarning` |
   | `UnusedShareMessage` | `LongUnusedWarning` |

**影响范围**: ShareRiskPage 完全不可用——所有计数显示 "--"，页面显示"无法读取分享安全状态"错误。

**严重级别**: **P0 (阻塞)**
