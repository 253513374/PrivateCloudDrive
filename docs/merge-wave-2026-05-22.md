# PrivateCloudDrive 阶段收口合并顺序（2026-05-22）

## 目的

在 `main` 受保护、且多条功能/验收 PR 并行存在时，明确当前阶段的推荐合并顺序，避免：

1. 在陈旧基线上继续派发后续任务
2. 重复 PR 长期并存
3. 相互依赖的 PR 倒序合并造成冲突或返工

## 当前原则

- 每完成一个阶段，优先把阶段成果合并回 `main`
- 后续任务必须从最新 `main` 派生
- 将“技术阻塞”和“仅剩非作者审批”的治理门禁严格区分
