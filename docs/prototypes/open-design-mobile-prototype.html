落地说明
1. 该 Claude Design 原型把参考图转译成 PrivateCloudDrive 自有 UI，不直接复制任何第三方产品。
2. 生产实现优先级：App Shell 与 Token → 文件首页 → 相册/媒体 → 我的/存储 → 动态任务中心。
3. AI、人脸、记忆、OCR 入口在 V1.2/V1.3 中必须灰显或隐藏，避免虚假承诺。
4. 文件、安全、容量、同步状态必须比装饰更重要。
