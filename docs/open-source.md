# PrivateCloudDrive 开源发布说明

日期：2026-05-21
负责人：Hermes 产品总监 / 何司令
文档定位：说明 PrivateCloudDrive 作为开源产品公开源代码时的许可证、边界、维护策略和文档入口。

---

## 1. 开源结论

PrivateCloudDrive 以 MIT License 开源。项目定位为：

> 自托管、移动优先、面向个人/家庭/小团队的私有文件与照片/视频备份网盘。

开源的核心目的不是展示代码，而是建立自托管数据产品的信任：源代码可审计、部署方式透明、密钥边界清晰、备份恢复可复现、产品路线公开。

## 4. 开源后的产品原则

1. 先证明“备份可信闭环”，再扩展泛网盘功能。
2. 新功能必须回答：解决谁的问题、影响哪些数据、如何验收、如何回滚。
3. 涉及密钥、登录、分享、删除、恢复、迁移的改动必须有安全说明。
4. 涉及 App 可见体验的改动必须有页面验收或截图证据。
5. 部署文档必须跟随配置变化更新。
